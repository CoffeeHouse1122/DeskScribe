DeskScribe 转写设置说明

本文档说明“偏好设置”中与转写速度、稳定性相关的选项。打包后可在安装目录的 resources/docs/transcription-settings.txt 查看。

1. 转写引擎

Whisper.cpp 稳定
- 默认推荐项，也是 DeskScribe 的保底方案。
- 使用内置 whisper-cli 和内置 ggml-small.bin 模型，开箱即可离线转写。
- 如果需要更高准确度，可以在设置中选择外部 ggml/gguf 模型，例如量化 large-v3。
- 适合只有 CPU、只有核显、离线环境、或不想额外安装 Python 依赖的电脑。
- 优点是部署简单、稳定、离线可用。
- 缺点是长录音速度通常慢于 Faster-Whisper，尤其使用 large-v3 这类大模型时。

Faster-Whisper 加速
- 使用 DeskScribe 内置 Python + faster-whisper/CTranslate2 运行。
- 安装包会携带 resources/python 运行时、faster-whisper 依赖，以及 resources/models/faster-whisper/distil-large-v3 模型。
- 用户不需要自行安装 Python 环境，也不需要运行时下载 Faster-Whisper 模型。
- 适合希望提升长录音转写效率的电脑。
- 有 NVIDIA CUDA 环境时通常收益最大。
- 没有独显、只有核显时，一般仍会走 CPU，但 CPU int8 模式也可能比 whisper.cpp 更快。
- 如果 Faster-Whisper 不可用或运行失败，DeskScribe 会自动回退到 Whisper.cpp 稳定方案。

2. 加速模型

distil-large-v3
- Faster-Whisper 当前内置使用的模型。
- 在准确度和速度之间比较均衡，适合会议、访谈、课堂、普通长录音。
- 如果你希望比 large-v3 更快，同时保持较好的准确度，优先选它。
- 为了保证打包后离线可用并避免用户下载模型，DeskScribe 不再在运行时切换/下载其他 Faster-Whisper 模型。

3. CPU 稳定模式

勾选 CPU 稳定模式
- 推荐给大多数普通电脑、只有核显的电脑、或曾经遇到 GPU 运行失败/崩溃的环境。
- Whisper.cpp 会明确禁用 GPU。
- Faster-Whisper 会优先使用 CPU int8，兼容性更好。
- 这里使用的是 DeskScribe 内置 Python 运行时，不依赖系统 Python。
- 速度可能不如 CUDA GPU，但稳定性更高。

取消勾选 CPU 稳定模式
- 适合已安装 GPU 版 whisper.cpp，或本机有可用 NVIDIA CUDA + faster-whisper 环境的电脑。
- Whisper.cpp 不再传递 --no-gpu，但是否真正使用 GPU 取决于你选择的 whisper-cli 是否带 CUDA/Vulkan/OpenVINO 等后端。
- 如果日志出现 “device 0: CPU” 或 “no GPU found”，说明当前运行时没有真正使用 GPU。
- 只有 Intel/AMD 核显时，通常不会得到明显 GPU 加速。

4. Whisper 线程数

默认值 4
- 更稳妥，适合多数电脑，避免转写时把系统占满。

设置为 0
- 自动按机器核心数分配线程，并限制不超过合理上限。
- 如果希望追求速度，可以先尝试 0。

手动设置具体数值
- 适合你希望控制 CPU 占用时使用。
- 数值不能超过当前机器可用逻辑线程数。
- 设置过高不一定更快，可能造成系统卡顿或线程争抢。

5. 长录音建议

- 如果只要求稳定且不想配置模型：选择 Whisper.cpp 稳定 + CPU 稳定模式，使用内置 ggml-small.bin。
- 如果希望 Whisper.cpp 更高准确度：在设置中选择外部 ggml-large-v3-q5_0.bin 或其他 ggml/gguf 模型。
- 如果希望更快：选择 Faster-Whisper 加速，使用内置 distil-large-v3。
- 如果有 NVIDIA CUDA：取消 CPU 稳定模式，并使用 Faster-Whisper 加速。DeskScribe 会优先使用内置 Python 运行时。
- 如果只有核显：建议保留 CPU 稳定模式；核显通常不会给 Whisper 带来明显加速。
- 如果安装包体积敏感：当前安装包只内置 ggml-small.bin，不内置 ggml-large-v3.bin 等大模型；使用 Whisper.cpp 时仍可在设置中选择外部模型文件。
