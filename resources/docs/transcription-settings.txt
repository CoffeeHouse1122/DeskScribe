DeskScribe 转写设置说明

本文档说明“偏好设置”中与转写模型、速度和计算设备相关的选项。打包后可在安装目录的 resources/docs/transcription-settings.txt 查看。

1. 转写引擎

Whisper.cpp 稳定
- 使用 DeskScribe 内置 whisper-cli 和本地模型库中的 Whisper.cpp 模型。
- 当前随应用打包的是 CPU 运行时，因此固定使用 CPU；设置页会禁用计算设备选项。
- Whisper Small 适合低配置设备，Large V3 Q5_0 适合更看重识别质量的中英文场景。
- 长录音速度通常慢于 Faster-Whisper，尤其使用 Large 系列模型时。

Faster-Whisper 加速
- 使用 DeskScribe 内置 Python、Faster-Whisper 和 CTranslate2 运行时。
- Large V3 Turbo 适合中文、英文和中英混合转写；Distil Large V3 定位为英语专项。
- 模型按需下载到 userData/models，应用更新不会覆盖，默认卸载也会保留。
- 支持 NVIDIA CUDA，CUDA 不可用或加载失败时自动回退到 CPU INT8。
- AMD、Intel 核显不会用于 Faster-Whisper 加速。

2. 本地模型库

- 下载完成后应用自动切换到该模型。
- 已安装多个模型时，可以点击“使用”进行切换。
- Faster-Whisper 模型和 Whisper.cpp 模型会自动切换到各自对应的转写引擎。
- 新模型由应用版本更新模型目录清单后提供，不需要手动选择模型文件。

3. 计算设备

选择 Faster-Whisper 时：
- 勾选“强制使用 CPU”：固定使用 CPU INT8，兼容性和稳定性更好。
- 取消勾选：优先探测 NVIDIA CUDA，使用 GPU Float16；CUDA 不可用时自动使用 CPU INT8。

选择 Whisper.cpp 时：
- 当前内置运行时仅支持 CPU，因此计算设备选项会被禁用并显示 CPU 状态。
- 如果以后随应用提供 GPU 版 Whisper.cpp 运行时，再开放对应 GPU 选项。

4. 转写线程数

- 设置为 0：按机器核心数自动分配，并限制在合理上限内。
- 设置具体数值：控制 CPU 占用，数值不会超过当前机器的逻辑线程数。
- Whisper.cpp 使用该值执行推理；Faster-Whisper 使用 GPU 时，该值主要影响 CPU 侧处理。

5. 使用建议

- 低配置或稳定优先：Whisper Small + Whisper.cpp。
- 中英文或混合语言：Large V3 Turbo + Faster-Whisper。
- 英语长音频和低延迟：Distil Large V3 + Faster-Whisper。
- 中英文质量优先且可以接受更长耗时：Large V3 Q5_0 + Whisper.cpp。
- 有 NVIDIA CUDA：使用 Faster-Whisper，并取消勾选“强制使用 CPU”。
- 只有 AMD、Intel 核显：建议勾选“强制使用 CPU”。
